MiSAD WEBSITE — Mising Students' Association, Delhi
====================================================

To update the site, edit content.js (photos, executive body, Lolad, contact).
The full step-by-step guide covers hosting, access and handover.

Folders
  assets/             logo (misad-logo.svg = master; PNGs at 512/1024/2048 px) and icons
  images/gallery/     event photos (web-sized, under 400 KB each)
  images/executive/   member photos (square, 600 x 600 px)
  images/samples/     PLACEHOLDERS: delete once real photos are added
  lolad/              Lolad PDFs and covers (lolad-sample.pdf is a placeholder)

The Lolad reader needs the site to be online (or run through a local server);
it cannot open PDFs when index.html is double-clicked from a folder.
